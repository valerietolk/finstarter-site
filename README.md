# FinStarter — сайт

Вёрстка по макету Figma (файл cYq7eMIYNFVB2I0VSWinVc): главная, How it works, Contact us.

## Структура

- `site/` — рабочая версия сайта. Открывается любым браузером: `site/index.html`.
  - `index.html`, `how-it-works.html`, `contact.html` — страницы
  - `styles.css` — общие стили (десктоп, 1920px по макету)
  - `responsive.css` — ноутбук / планшет / телефон (≤1280 / ≤1024 / ≤900 / ≤768 / ≤640)
  - `how-it-works.css`, `contact.css` — стили страниц
  - `hero-dark.css` — тёмный герой главной (эксперимент; выключается классом `hero-dark` на `<body>`)
  - `site.js` — общее поведение (меню, дропдаун, модалка Book a Demo, FAQ, анимации)
  - `how-it-works.js`, `contact.js` — поведение страниц
  - `liquid.js` — живой градиентный фон (WebGL); сейчас не подключён, оставлен на будущее
  - `assets/` — картинки и иконки, экспортированные из Figma; `assets/hero/` — карточки hero-сцены по отдельности, `assets/feature-portrait/` — портретные варианты feature-карточек для планшета
- `backups/` — снимки на важных этапах (v5 — чистая вёрстка по Figma, v11 — десктоп до адаптива, v14 — перед страницей How it works).
- `tools/` — служебные скрипты (сборка копии для артефакта, локальный сервер, выгрузка из Figma).
